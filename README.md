IF DOWNLOADING FROM GITHUB 
Note: You need Github desktop and Godot 4 installed on computer.
1) Copy the URL of this 91906 repository
2) Open github desktop
3) Go to file -> Clone repository
4) Select URL, paste the URL link, choose a folder for the files then click clone
5) Launch Godot
6) Click Import
7) Browse your computer and find the project file downloaded from github desktop, then select open.
8) Click import and edit to open the project in the Godot Editor
9) Press F5 or the little play button in the corner to run the game.
